# ZRX/USD Time Series & Predictive Modeling

A team project analyzing and forecasting the ZRX/USD cryptocurrency exchange rate using time-series methods and regression-based predictive modeling.

## Project Overview

The analysis studies daily ZRX/USD market data from January 2023 through February 2024 and evaluates whether trading variables such as bid price, ask price, volume, and time help explain exchange-rate movements.

## Methods

- Exploratory time-series analysis
- Trend and stationarity assessment
- Regression modeling
- Predictor selection
- Residual diagnostics
- Forecasting

## Data

The project uses `ZRXUSD.csv`, containing daily market variables including high, low, mid, last, bid, ask, and trading volume.
